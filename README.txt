Lenoc Shelters website media update

Contents:
- index.html (updated live-site page with gallery and videos)
- assets/ (18 web-optimized property photos + 2 videos)

How to update GitHub for Render:
1. Open your GitHub repository: allenikem-hash/lenoc-shelters-website
2. Upload and replace index.html with the one in this package.
3. Upload the entire assets folder to the repository root.
4. Commit the changes to the main branch.
5. Render will auto-deploy the update.

After deployment, the site will show:
- 5-bedroom bungalow featured sale video
- 18 rental property photos
- 1 additional property video tour
- Property valuation service
- WhatsApp contact and enquiry buttons
